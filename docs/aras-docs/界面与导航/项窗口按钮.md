<h1>条目窗口按钮</h1>
<p class="Content_body">条目窗口中显示的按钮提供了查看与该条目关联的访问权限、条目历史记录、版本历史记录等选项。下表描述了各按钮及其相关选项。</p>
<!--?rh-list_start level="1" an="1" class="rl-p-Note" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Note">某些选项可能显示为禁用状态。菜单选项在选中相应条目且登录用户拥有足够访问权限时才会启用。访问权限由管理员配置。</p>
