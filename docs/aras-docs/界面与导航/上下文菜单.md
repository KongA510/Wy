<h1>上下文菜单（右键菜单）</h1>
<p class="Content_body">当您在主网格中对条目使用鼠标右键（右键单击）时，将出现上下文菜单。上下文菜单中包含的选项可能因网格类型而异。以下示例显示了 ItemType（物料类型）搜索网格：</p>
<p class="Content_body"><img :src="'/aras-images/itemtypelist.jpg'"></p>

<p class="Content_body">. 下表解释了上下文菜单中可用的每个选项。</p>
<!--?rh-list_start level="1" an="1" class="rl-p-Note" style="list-style: rh-list;
list-style: rh-list;" ?-->
