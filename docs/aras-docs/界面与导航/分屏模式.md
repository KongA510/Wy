# 使用分屏模式
<p>分屏模式允许用户通过点击标题栏中的分屏按钮来启用或禁用并排视图：</p>

<p><img height="362" :src="'/aras-images/splitheader.jpg'" style="cursor: nwse-resize;" width="948"></p>

<p>以下示例展示了分屏视图，左侧为零件搜索网格，右侧为各个零件条目。</p>

<p><img height="467" :src="'/aras-images/sidebysideview.jpg'" width="842"></p>

<p>零件搜索网格已停靠。右侧的选项卡为浮动状态，并显示活动选项卡。点击左侧面板中的选项卡可在右侧面板中打开该条目。</p>

## 使用上下文菜单
<p>右键单击任一面板可查看上下文菜单。</p>

<p><img height="351" :src="'/aras-images/splitcontext.jpg'" width="884"></p>

<p>上下文菜单允许您关闭特定选项卡、所选选项卡、屏幕左侧或右侧的所有选项卡，或所有选项卡。点击"分离选项卡"可关闭所有选项卡。点击"停靠选项卡"可将浮动选项卡切换为停靠状态。</p>

## 更改分屏比例
<p>您可以通过点击并拖动面板分隔线来更改分屏面板的比例。</p>

<p><img height="454" :src="'/aras-images/resizeprops.jpg'" width="886"></p>

<p>将鼠标悬停在面板分隔线上。会出现一个双箭头，分隔线会变色以表示可以更改面板比例。</p>

<p><img height="464" :src="'/aras-images/hoverdivide.jpg'" width="907"></p>

<p>拖动分隔线以调整比例。</p>

<p><img height="470" :src="'/aras-images/slidedivide.jpg'" width="915"></p>
