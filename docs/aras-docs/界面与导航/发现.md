# 关于发现权限
<p class="Content_body">发现权限提供了进一步限制对 Aras Innovator 数据库中条目访问的能力。发现权限决定了身份组是否被允许了解条目存在于 Aras Innovator 数据库中。此功能可用于限制开发或供应链合作伙伴只能发现他们负责的 Aras Innovator 数据库中的条目。在这种情况下，即使其他条目匹配搜索条件，搜索结果中也只会返回设置了"可发现"访问权限的条目。</p>
