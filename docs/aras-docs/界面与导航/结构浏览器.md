# 结构浏览器（Structure Browser）
<p class="Content_body">每个 Innovator ItemType（物料类型）可以包含一个或多个关系实例。结构浏览器用于以可展开的格式快速查看关系实例。这种查看方式在零件结构（如物料清单 BOM）或查看 ItemType 之间的复杂关系时最为有用。</p>
<p class="Content_body">您可以通过在主网格中右键单击条目（Item）打开上下文菜单来访问结构浏览器。</p>
<p class="Figure_indented"><img :src="'/aras-images/structurebrowse.jpg'"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->

<!--?rh-list_end ?-->
<p class="Content_body"><span class="Bold">结构浏览器（Structure Browser）</span>窗口以单行显示所选条目，格式为 <b>ItemType - 名称 - 修订版.版本号 <span style="font-weight: normal;">。您可以单击 <img alt="" class="Image" :src="'/aras-images/Structure_browser_expand_icon.jpg'"> 来展开和查看关系实例的结构。</span></b></p>

<p class="Content_body">在示例中，我们使用一个简单的物料清单（BOM）来展示结构浏览器的简洁性。</p>
<p class="Procedure_Title"><a id="To_open_an_ItemType_in_a_Structure_Browser" name="To_open_an_ItemType_in_a_Structure_Browser"></a>在结构浏览器中打开条目</p>
<!--?rh-list_start class="Numbered_list" mc="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">登录 Aras Innovator。</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" mc="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<li class="Numbered">从目录（TOC）导航到条目。</li>
<!--?rh-list_end ?-->
<li class="Numbered">让我们以零件 ItemType 为例。导航到 <span class="Bold">设计（Design）--&gt; 零件（Parts）</span>。</li>

list-style: rh-list; list-style: rh-list;" ?-->
<li class="Numbered">从主网格中选择条目，然后使用鼠标右键（右键单击）打开上下文菜单。</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" mc="1" style="font-size: 11pt;
list-style: rh-list; list-style: rh-list;" ?-->
<li class="Numbered">选择 <span class="Bold">结构浏览器（Structure Browser）</span>。</li>
<!--?rh-list_end ?-->
<li class="Numbered"><span class="Bold">结构浏览器</span>窗口出现。</li>
<li class="Content_body">单击 <img :src="'/aras-images/expandall.jpg'"> 查看零件条目的关系。</li>
</ol>
