<div>
<h1>事件</h1>
<p class="Content_body">字段事件和表单事件使方法能够根据用户操作在客户端或服务器端执行。方法存储在 Innovator 中，如"方法"章节所述。事件可以由用户操作触发（如鼠标事件——点击、移动），也可以由页面操作触发（如加载或打印）。方法可以在客户端或服务器上执行，具体取决于方法代码中的定义。</p>
