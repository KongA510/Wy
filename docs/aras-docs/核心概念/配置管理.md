<h1>关于配置管理</h1>
<p class="Content_body">配置管理是通过管理组织的产品、设施和流程的需求（包括变更），并确保每个环节的结果符合要求，从而对它们进行管理的过程。</p>
<p class="Content_body">Innovator 中所有条目都具有生命周期（LifeCycle），并且条目可以是可版本化的。Innovator 中对可版本化条目的更改通过版本（Version）、修订版（Revision）和行为来实现，这些都是 Innovator 框架的一部分。</p>
<p><a href="#" class="internal-doc-link">关于版本</a></p>
<p><a href="#" class="internal-doc-link">关于修订版</a></p>
<p><a href="#" class="internal-doc-link">生命周期条目行为</a></p>
<p><a href="#" class="internal-doc-link">RelationshipType 条目行为</a></p>
<p class="Content_body">产品工程解决方案利用 Innovator 框架将配置管理应用于零件（Part）和文档（Document）。类似的功能也可应用于其他 Innovator 条目。</p>
