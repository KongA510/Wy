# 创建动作
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<p class="Numbered">1. 在导航窗格中，选择 <strong>管理&gt;动作</strong>。出现以下菜单：</p>
<p class="Numbered"><img :src="'/aras-images/actions.jpg'"></p>
<p class="Numbered">2. 选择 <strong>创建新动作</strong>。一个空白的动作窗口随即显示：</p>
<p class="Numbered"><img :src="'/aras-images/actionscreen.jpg'"></p>

<p class="Numbered">3. 在各字段中输入相应的信息。</p>
<p class="Numbered">4. 点击 <img :src="'/aras-images/save.jpg'"> 和 <img :src="'/aras-images/done.jpg'"> 以保存并释放该条目。</p>
