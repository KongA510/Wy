# 删除方法
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">在导航窗格中，选择<strong>Administration&gt;Methods</strong>。将出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/methodmenu.jpg'"></p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<ol start="2">
<li class="Numbered">点击<strong>Search Methods</strong>。搜索网格将出现。</li>
<li class="Numbered">点击<img :src="'/aras-images/searchbutton.jpg'">查看方法列表。</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/methodlist.jpg'"></p>

<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<ol start="4">
<li class="Numbered">右键点击要删除的方法。将出现以下上下文菜单：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/contextmenu2.jpg'"></p>

<ol start="5">
<li class="Numbered">选择<strong>Purge This Version</strong>以删除方法的最新版本。选择<strong>Delete All Versions</strong>以删除方法的所有版本。将出现类似以下的对话框：</li>
</ol>
<p><img :src="'/aras-images/purgemethod.jpg'">
</p>
<ol start="6">
<li class="Numbered">点击<strong>OK</strong>。</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="rl-p-Note" an="1" level="1" style="font-size: 11pt;
list-style: rh-list; list-style: rh-list;" ?-->
</ol>
<p class="Note_indented">注意：如果在确认弹窗之后出现错误消息，表示该条目未被删除。错误消息中会出现对应ItemType（物料类型）的属性名称，格式为[itemtype_name property_name}，该属性必须从ItemType（物料类型）中删除。</p>
<!--?rh-list_end ?-->
