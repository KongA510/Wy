<h1>高级搜索</h1>
<p class="Content_body">高级搜索模式是一个向导，允许您使用简单搜索中无法使用的属性和搜索条件来执行搜索。</p>
<p class="Content_body">高级搜索允许您：</p>
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ul style="list-style-type: disc;">
<li class="Bulleted_list" style="margin-left: 50px;">对关系以及源条目进行搜索<span style="font-size: 7.0pt; font-family: 'Times New Roman';">   </span>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list" style="margin-left: 50px;">对主网格中未显示的属性进行搜索
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list" style="margin-left: 50px;">使用运算符（如"大于"或"不等于"），而非使用带通配符的"等于"</li>
</ul>
<!--?rh-list_end ?-->

<p class="Procedure_Title">创建高级搜索</p>

<ol>
<li class="Numbered">在搜索工具栏中单击"添加条件" <img :src="'/aras-images/AddCriteria.jpg'"> 按钮，为所有要使用的条件添加行。<br>
</li>
<li class="Numbered">对于不需要的条件，右键单击并从上下文菜单中选择"删除条件"进行删除。<br>
</li>
<li class="Numbered">对于每个条件行，选择：<br>
<ul>
<li class="Numbered">一个 ItemType</li>
<li class="Numbered">一个属性</li>
<li class="Numbered"><span style="text-align:left;">一个运算符</span></li>
<li class="Numbered"><span style="text-align:left;">一个条件值<br>
</span><span style="text-align:left;"></span></li>
</ul>
</li>
<li>在搜索工具栏中单击"搜索"按钮。<br>
</li>
<li>
<!--?rh-list_end ?-->根据需要使用搜索工具栏中的"停止搜索"和"清除搜索"按钮。</li>
</ol>
