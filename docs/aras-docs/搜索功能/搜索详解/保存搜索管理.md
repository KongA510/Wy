# 已保存搜索管理
<p class="Content_body">已保存搜索显示在目录（TOC）的管理类别中</p>

<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<p class="Figure_indented"><img :src="'/aras-images/savesearch1.jpg'"></p>
<!--?rh-list_end ?-->
<p class="Content_body">主网格中显示的列如下：</p>
<!--?rh-list_start class="Bullet_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<ul class="Disc">
<li class="Bulleted_list"><b style="font-weight: bold;">标签：</b>已保存搜索的标签，显示在工具栏的已保存搜索区域中。对于自动保存的搜索，此列为空。</li>
</ul>

<ul class="Disc">
<li class="Bulleted_list"><b><span style="font-weight: bold;">ItemType</span>：</b>搜索所适用的 ItemType 的名称。</li>
</ul>

<ul class="Disc">
<li class="Bulleted_list"><b>搜索模式：</b>当搜索首次保存时，此列显示用于创建搜索的搜索模式。可以通过单击该列中的相应链接并编辑该项来更改。选择<span style="font-weight: bold;">无界面</span>模式后，选择已保存搜索时将隐藏搜索详细信息。</li>
</ul>




<ul class="Disc">
<li class="Content_body_indented">如果所选搜索模式无法显示搜索条件（例如，在 AML 模式下创建的搜索使用了简单搜索模式，但条件无法在简单搜索模式中表示），则会使用能够表示该条件的最简单模式。模式层级为：简单、高级、AML。

</li>
<li><b><span style="font-weight: bold;">条</span>件：</b>所有搜索的条件均以相同格式显示，即&nbsp;Aras 标记语言（AML），它是 Aras Innovator 的基础语言。熟悉 AML 的管理员可以在已保存搜索显示在主网格中时，通过创建新项来直接创建已保存搜索。有关 AML 的更多信息，请参阅程序员指南或 API 类参考。</li>
</ul>

<!--?rh-list_start class="Bullet_list" mc="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<ul class="Disc">
<li class="Bulleted_list"><b><span style="font-weight: bold;">位</span>置：</b> 此处显示搜索将在哪里使用：</li>
</ul>
<!--?rh-list_end ?-->
<!--?rh-list_start level="2" class="Bullet_list" mc="1" ic="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<p class="Content_body_indented">主网格</p>
<p class="Content_body_indented">关系网格<br>
搜索对话框</p>

<ul class="Disc">
<li class="Bulleted_list"><strong>自动保存：</strong>此列中的勾选标记表示搜索是自动保存的。</li>
<li class="Content_body"><strong>Owned_by_id：</strong>显示创建该搜索的身份组。</li>
<li class="Content_body"><strong>Managed_by_id：</strong>显示管理该搜索的身份组。</li>
<li class="Content_body"><strong>在目录中显示：</strong>勾选标记表示已保存搜索显示在导航窗格中。</li>
</ul>
<p class="Content_body">使用主菜单保存主网格的搜索，使用项目窗口菜单保存关系网格的搜索。</p>
<p class="Procedure_Title">要为搜索对话框创建搜索，请执行以下操作之一：</p>
<ul>
<li style="list-style: disc;">
<p class="Content_body">为主网格或关系网格创建搜索，然后编辑已保存搜索以更改位置。</p>
</li>
<li style="list-style: disc;">
<p class="Content_body">在管理树中直接创建已保存搜索：</p>
</li>
</ul>
<!--?rh-list_start class="Bullet_list" level="2" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<p class="Content_body_indented"><b><span style="font-weight: bold;">自动保存</span>：</b>当您发起搜索时，搜索会自动保存，此时 auto_saved 设置为 1。当从菜单保存搜索或从管理树创建搜索时，自动保存设置为 0。</p>
<p class="Content_body_indented"><b>owned_by_id：<span style="font-weight: normal;">自动</span></b>设置为创建搜索的用户的别名身份，并具有该项的获取访问权限。管理者或管理员可以更改此设置。</p>
