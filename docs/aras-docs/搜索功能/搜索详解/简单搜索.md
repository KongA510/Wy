# 简单搜索
<p class="Content_body">简单搜索是最简单且最常用的搜索方式。默认情况下，搜索工具栏会显示简单搜索。以下是一些提升搜索效果的实用技巧。</p>

<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Figure_indented"><img height="169" :src="'/aras-images/partnewtoolbar.jpg'" style="cursor: nesw-resize;" width="783"></p>
<!--?rh-list_end ?-->
<p class="Procedure_Title">简单搜索技巧</p>
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<ul class="Disc">
<li class="Bulleted_list">使用 * 或 % 作为通配符。例如，在<span class="Bold">名称</span>列中输入 'a*b' 表示搜索以 'a' 开头且以 'b' 结尾的任意条目。如果（搜索菜单中的）<span class="Bold">使用通配符</span>选项被禁用，则 * 和 % 字符将按原样识别，不会被视为通配符。

</li>
<li class="Bulleted_list">单独使用 * 可选择非空值。<br>
<br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" mc="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list">使用 | 可在单个属性中设置多个条件。例如，如果在<span style="font-weight: bold;">类型</span>列中输入 Material|Component，则所有属于<span style="font-weight: bold;">Material</span> 或 <span style="font-weight: bold;">Component</span> 类型的条目都会显示在搜索网格中。<br>
<br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list">使用 \\ 可搜索包含 \ 的条目。</li>
</ul>
<!--?rh-list_end ?-->
<!--?rh-list_start class="rl-p-Note" level="1" an="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Note_indented">注：字符 | 和 \ 是保留字符，无法直接搜索。<span style="font-size: 10.0pt; font-family: Arial, sans-serif; mso-fareast-font-family: Calibri; mso-fareast-theme-font: minor-latin; mso-ansi-language: EN-US; mso-fareast-language: EN-US; mso-bidi-language: AR-SA;">要搜索这些字符，需要在保留字符前放置转义字符 \。</span>例如，要搜索行业 Aeropsace\Defense，请在行业列中输入 Aeropsace\\Defense。所有属于 Aerospace\Defense 行业的条目将显示在搜索网格中。</p>
<!--?rh-list_end ?-->

<ul class="Disc">
<li class="Bulleted_list">使用 @{n}（其中 n 为数字）可创建<a href="#" class="internal-doc-link">参数化搜索</a>。<br>
<br>
<span data-condition="Others:Ignore">
<!--?rh-list_end ?--></span>
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list">对于包含复选框的列，使用 0 或 1，0 表示未选中。<br>
<br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list">通过键入名称搜索条目。例如，输入 'Adm*' 可找到名为 Administrators 的身份组。<br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" style="list-style: rh-list; list-style: rh-list;" ?--><br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" style="list-style: rh-list; list-style: rh-list;" ?-->
</li>
<li class="Bulleted_list">点击蓝色搜索栏最左侧列中的 <img alt="" class="Image" :src="'/aras-images/Simple_search_lock_column_arrow.jpg'"> 可按认领状态进行搜索。</li>
</ul>

#### 示例：
<p class="Content_body">在蓝色搜索栏的<span class="Bold">名称</span>列中输入 'RC*'，可显示零件号以字母 "RC" 开头的条目。</p>

<p><b>日期搜索</b> </p>
<p class="Content_body">简单搜索模式现在支持对日期属性使用运算符进行搜索，包括 &gt;、&gt;=、&lt;、&lt;= 和（范围）。搜索选项如下，其中 {Date} 表示标准短日期格式：</p>
<ul class="Disc">
<li class="Bulleted_list">{Date} 返回日期值与搜索值完全匹配的结果。</li>
<li class="Bulleted_list">
<p class="Bulleted_list">&gt;={Date} 返回日期晚于（或等于）指定日期的结果。</p>
</li>
<li class="Bulleted_list">
<p class="Bulleted_list">&lt;={Date} 返回日期早于（或等于）指定日期的结果。</p>
</li>
<li class="Bulleted_list">{Date}...{Date} 返回值在两个值之间（含两端）的结果。</li>
</ul>
<p class="Note">注：{Date} 文本可以手动输入，也可以通过日期对话框选择。</p>
