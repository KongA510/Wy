# 已保存搜索
<p class="Content_body">已保存搜索 ItemType 使用户能够检索之前创建的搜索；这些搜索可以通过多种方式使用。</p>
#### 用户的已保存搜索
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ul style="list-style-type: disc;">
<li class="Bulleted_list">
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Bulleted_list">在执行搜索后，您可以将其保存并命名，以便将来检索和重复使用，无论是否进行修改。</p>
</li>
<li class="Bulleted_list">
<p class="Bulleted_list"><span style="font-size: 11.5pt;">每次执行搜索时，搜索模式和搜索条件都会自动保存。当您返回某个条目时，上次的搜索将自动恢复。</span></p>
</li>
<li class="Bulleted_list">
<p class="Bulleted_list">每个用户都可以执行自己创建的已保存搜索，以及其他用户共享的搜索。</p>
</li>
</ul>


## 保存搜索
<ol>
<li class="Numbered">在任意搜索模式下执行搜索。</li>
<li class="Numbered">单击<strong>添加到收藏</strong>按钮 <img :src="'/aras-images/adtofav.jpg'"> 以保存搜索。将出现收藏搜索对话框。<br>
<img :src="'/aras-images/favesearch.jpg'" style="border-width: 1px; border-style: none; border-color: rgb(0, 0, 255);"></li>
<li class="Numbered">在<strong>标签</strong>字段中输入搜索的名称。</li>
<li class="Numbered">单击<strong>共享给：</strong>字段中的省略号，与组织中的其他 Aras Innovator 用户共享此搜索。</li>
<li class="Numbered">选中<b>固定到快速访问</b>复选框，以便在目录中显示该搜索的快捷图标 <img :src="'/aras-images/favs.jpg'"> 。</li>
<li class="Numbered">单击<strong>保存</strong>。您可以通过在导航面板中选择管理&gt;已保存搜索来访问该搜索。</li>
</ol>

## 检索/应用已保存搜索
<ol style="list-style-type: decimal;">
<li class="Numbered">登录 Aras Innovator。</li>
<li class="Numbered">在目录中选择<strong>管理&gt;已保存搜索</strong>。将显示已保存搜索网格。已保存搜索菜单如下所示：<br>
<br>
<img :src="'/aras-images/savedsearchmenu.jpg'"></li>
<li class="Numbered">单击<strong>搜索已保存搜索</strong>以查看已保存搜索列表。</li>
<li class="Numbered">右键单击要执行的搜索，然后单击<strong>运行</strong>。</li>
</ol>
## 删除已保存搜索
<ol style="list-style-type: decimal;">
<li class="Numbered">登录 Aras Innovator。</li>
<li class="Numbered">在导航面板中选择<strong>管理&gt;已保存搜索</strong>。将显示已保存搜索网格。</li>
<li class="Numbered">单击 <img :src="'/aras-images/searchbutton.jpg'"> 以查看已保存搜索列表。</li>
<li class="Numbered">右键单击要删除的搜索，然后从上下文菜单中选择<strong>删除所有版本</strong>。将出现类似以下的对话框。<br>
<br>
<img :src="'/aras-images/delsearch.jpg'"></li>
<li class="Numbered">单击<strong>确定</strong>。</li>
</ol>
