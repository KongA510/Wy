# 配置有效性管理
<p>零件 BOM（物料清单）结构的有效性管理在产品工程（PE）应用程序中可用。该功能支持在 BOM（物料清单）中表达零件的有效性条件，并根据这些条件解析 BOM（物料清单）结构。作为管理员，您可以在 PE 应用程序中配置和自定义有效性管理的某些方面，例如：</p>
<ul class="Disc">
<li>创建额外的有效性变量和有效性范围。</li>
<li>自定义有效性范围构建器方法以实现自定义业务逻辑。</li>
<li>配置查询定义用于结构解析逻辑。</li>
<li>配置树形网格视图以显示条目和关系属性。</li>
<li>配置权限以确定有效性信息。</li>
</ul>
<p class="Note">effs_ 名称前缀用于属于有效性管理的 ItemType（物料类型）。</p>
## 有效性服务数据模型概述
<p>本节提供了在 PE 中实现的基于有效性服务的数据模型概念的高级概述。有关更多信息，请参阅 <strong>Aras Innovator 12.0 - 有效性服务程序员指南</strong>。</p>
<p>有效性范围定义了一个使用有效性条件进行解析的上下文，该条件应应用于特定的有效条目。有效性范围由以下条目组成：</p>
<ul class="Disc">
<li>有效性变量，即影响有效性决策的变量。</li>
<li>有效性范围 ItemType（物料类型），用于确定需要通过有效性解析的条目。</li>
</ul>
<p>构建器方法使用有效性变量在运行时构造范围对象，供有效性解析引擎用于执行有效条目的解析。</p>

## 有效性服务、TGV 和 QD 事务概述
<p>用户通过树形网格视图（TGV）交互来提供用于结构解析的有效性条件。TGV 从关联的查询定义（QD）请求必要的数据。有效性条件通过查询定义参数传递给查询定义。</p>
<p>查询定义使用提供的有效性条件请求有效性表达式条目。有效性解析引擎根据提供的有效性条件解析有效性表达式条目，然后返回结果。结果显示在树形网格视图中。</p>
