# 报表
<p>报表允许用户以布局清晰、组织有序的方式查看复杂的多层级信息。对于任何零件，有三种类型的报表可供使用：</p>
<ul class="Disc">
<li><strong><span class="MenuChoice">多层级 <a class="glossterm" data-rhwidget="ExpandSpot" data-target="glossary">BOM</a><span class="expanding-content" data-targetname="glossary"> </span> 报表</span> </strong>- 显示父级零件 BOM（物料清单）中的所有零件，以及它们在层级结构中的位置和数量；</li>
<li><strong><span class="MenuChoice">BOM 数量汇总报表</span> </strong>- 显示顶层零件所需的所有零件及其数量；</li>
<li><strong><span class="MenuChoice">BOM 成本报表</span> </strong>- 根据子级零件的实际成本或估算成本计算零件的总成本。</li>
</ul>
<ol class="Decimal"><br>
<li>要访问这些报表，请在导航窗格中选择 <strong>设计&gt;零件</strong>。将出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/partmenu.jpg'"></p>
<ol class="Numbered" start="2">
<li class="Numbered">
<p>点击 <strong>搜索零件</strong>。零件网格将显示。</p>
<p class="Figure_indented"><img :src="'/aras-images/partgrid.jpg'"></p>
</li>
<li class="Numbered">
<p>点击 <img :src="'/aras-images/searchbutton.jpg'"> 查看零件列表。</p>
</li>
<li class="Numbered">
<p>右键点击网格中的某个零件，然后从弹出菜单中选择您想要的报表。</p>
</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/partsmenu.jpg'"></p>

<ol class="Decimal">
<li>在导航窗格中选择 <strong>管理&gt;报表</strong>。将出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/reportmenu.jpg'"></p>
<ol class="Decimal" start="2">
<li>点击 <strong>搜索报表</strong>。报表搜索网格将显示。</li>
