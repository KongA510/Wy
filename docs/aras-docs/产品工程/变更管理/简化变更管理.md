# 简化变更管理简介
<p>简化变更管理是用于启动、设计、审核和实施对零件或文档变更的流程。受控的变更使企业能够改进其产品并取得更大的成功。简化变更管理是减少管理开销并快速实施已发布零件或文档的有效方法。您还可以修改零件的已批准制造商列表（AML）以进一步增强性能。</p>
<p>简化变更管理使用更少的变更条目和更简单的方法来影响零件和文档的变更。与默认的 CMII 分阶段流程相比，此流程是一种更简单的变更管理方式。虽然 CMII 仍被视为最佳实践，但您可以同时使用简化变更管理。</p>
<p>简化变更管理使用以下基本 ItemType（物料类型）：</p>
<ul class="Disc">
<li>
<p>工程变更单（ECO） - 使用工程变更单对零件和文档进行变更。您还可以使用 ECO 通知用户条目已发生变更。ECO 通过从流程中移除 PR 和 ECR，为 CMII 流程提供了一种简单的替代方案。有三种类型的变更：添加、修改和删除。ECO 是 CMII 流程的简单替代方案，因为它从流程中移除了 PR 和 ECR。使用 ECO 来修改、添加或删除零件或文档。</p>
</li>
<li>
<p>制造变更单（MCO） - 在零件发布后，使用制造变更单编辑已批准制造商列表（AML）。MCO 的简洁性避免了此类变更需要通过整个 ECN 流程传播的需要。</p>
</li>
<li>
<p>快速文档变更单（DCO） - 使用快速文档变更单在组织内快速实施文档和 CAD 文档的变更。</p>
</li>
</ul>
