# 关于产品工程
<p>Aras 产品工程是一个开箱即用的解决方案，用于跨公司以及与供应商和客户之间进行产品定义和工程变更管理。</p>
<p>开发指标在持续的工程过程中收集，用于衡量目标完成进度，并以图表、报告和记分卡的形式呈现，以实现可视化管理。</p>
## 优势
<ul class="Disc">
<li>
<p>可视化的关键开发指标可提高工程效率，并为持续改进提供依据</p>
</li>
<li>
<p>通过安全的在线方式管理产品定义流程，按时按预算开发高质量产品</p>
</li>
<li>
<p>工程变更管理缩短周期时间并简化业务运营</p>
</li>
<li>
<p>控制部门、分支机构、供应商和客户之间的产品信息发布，实现高效协调</p>
</li>
<li>
<p>产品和工艺信息的重用可提高生产力并控制成本</p>
</li>
<li>
<p>采用 CMII 原则和流程，融入配置管理和工程变更的行业最佳实践</p>
</li>
<li>
<p>无与伦比的灵活性使应用程序能够针对自有工程流程和特定竞争实践进行定制修改</p>
</li>
</ul>
