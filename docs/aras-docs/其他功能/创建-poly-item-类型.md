<h1>Creating a Poly Item Item Type</h1>
<p class="Content_body">Use the following procedure:</p>
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">In the Navigation pane, click&nbsp;<span class="MenuChoice" style="font-weight: bold;">Administratio</span><span class="MenuChoice">n</span>&gt;<span class="MenuChoice" style="font-weight: bold;">ItemType</span>. The following menu appears:</li>
</ol>
<p class="Figure_indented" style="margin-left: 50px;"><img alt="" :src="'/aras-images/itemenu.jpg'"></p>

<ol start="2">
<li class="Numbered">Click <strong>Create New ItemType</strong>. An blank ItemType window appears.</li>
</ol>
<p class="Figure_indented" style="margin-left: 50px;"><img alt="" :src="'/aras-images/blankitem.jpg'"></p>
<ol start="3">
<li class="Numbered">Enter data for the header properties of your new Item Type, selecting <strong>Poly Item</strong> for the implementation type.</li>
</ol>
<p class="Content_body_indented"><img alt="" :src="'/aras-images/implement.jpg'"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<p class="Figure_indented">You will receive the following warning. &nbsp;</p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->

<p class="Content_body_indented"><img :src="'/aras-images/ploywarn.jpg'"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<p class="Figure_indented">Note that many of the relationship tabs are disabled when selecting the Poly Item type</p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<ol start="4">
<li class="Numbered">Click&nbsp;<strong>OK</strong>.</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<li class="Numbered">Click the “Poly Sources” relationship tab &nbsp;&nbsp;</li>
</ol>
<!--?rh-list_end ?-->

<p class="Content_body_indented"><img alt="" height="80" :src="'/aras-images/polytab.jpg'" width="848"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<ol start="6">
<li class="Numbered">Select existing ItemTypes that the Poly Item will support. For example, the following could be a list for the Deliverable Item Type.</li>
</ol>
<!--?rh-list_end ?-->

<p class="Content_body_indented"><img :src="'/aras-images/polyrel.jpg'"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list; 
list-style: rh-list;" ?-->

<!--?rh-list_end ?-->

list-style: rh-list;" ?-->

<ol start="7">
<li class="Numbered">Select the <strong>Properties </strong>tab. &nbsp;Enter any common property names that you would like to display in selection search item browser grids. &nbsp;If a property name is added that does not exist in all the Poly Sources,
then an error similar to the following will be thrown when saving the ItemType.</li>
</ol>
