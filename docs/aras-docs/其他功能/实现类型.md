<h1>实现类型</h1>
<p class="Content_body">一个 ItemType（物料类型）可以通过两种不同的实现方式来定义——单一条目（Single Item）和多态条目（Poly Item）。</p>

<h2>单一条目（Single Item）</h2>
<p class="Content_body">单一条目类型是最常见的实现方式。在单一条目模式下，每个 ItemType 代表一个独立的业务对象，并在关系型数据库中以单张表的形式表示。单一条目类型的示例包括零件（Part）、文档（Document）、项目（Project）、DFMEA 等的定义。</p>
<h2>多态条目（Poly Item）</h2>
<p class="Content_body">多态条目实现类型代表 ItemType 的多态类。一个多态条目 ItemType 可以表示一组其他 ItemType 的集合。多态（Poly Item）ItemType 通常用于某个条目的属性可以引用多种可能的条目类型的情况——例如项目交付物。交付物的类型可以是多种可能的条目类型之一，例如文档、零件、控制计划等。</p>
<p class="Content_body">多态条目类型在 ItemType 定义中兼容的关系（Relationship）类型集合相对有限。只有那些在 ItemType 表单中保持活动状态的选项卡（Tab）才会在多态条目类型中得到支持。</p>
