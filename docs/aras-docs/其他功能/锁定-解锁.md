<h1>认领或取消认领条目</h1>
<p class="Content_body">如果您拥有所需的访问权限，可以认领或取消认领条目。当您认领一个条目时，可以防止其他用户对该条目进行更改。取消认领条目后，其他用户将可以认领该条目并进行更改。</p>
<p class="Procedure_Title">认领条目</p>
<p class="Content_body">在主网格中选择条目，然后选择以下方式之一：</p>
<ul class="Bullet_list">
<li>
<p class="Bulleted_list">在主网格中右键单击条目，然后选择 <img height="25" :src="'/aras-images/ClaimOff.svg'" width="25"> 按钮。</p>
</li>
<li>
<p class="Bulleted_list">打开条目，然后在条目工具栏中选择 <img height="25" :src="'/aras-images/ClaimOff.svg'" width="25"> 按钮。</p>
</li>
<li>
<p class="Bulleted_list">打开条目，然后在条目工具栏中选择 <img height="25" :src="'/aras-images/edit.jpg'" width="47"> 按钮。</p>
</li>
</ul>
<p class="Note_indented">选择 <img height="25" :src="'/aras-images/edit.jpg'" width="47"> 选项意味着条目将在用户点击 <img height="25" :src="'/aras-images/done.jpg'" width="56"> 或 <img height="25" :src="'/aras-images/Discard.jpg'" width="60"> 按钮，或注销后自动取消认领。</p>

<p class="Procedure_Title">取消认领条目</p>
<p class="Content_body">有多种方式可以取消认领条目。在主网格中选择您已认领的条目，然后执行以下操作之一：</p>
<p class="Note">您只能取消认领由您认领的条目。您无法取消认领带有红色标记（由其他用户认领）的条目。只有管理员才有权限覆盖其他用户的认领。</p>
<ul class="Bullet_list">
<li>
<p class="Bulleted_list">在主网格中右键单击条目，然后点击 <img height="25" :src="'/aras-images/ClaimOn.svg'" width="25"> 按钮。</p>
</li>
<li>
<p class="Bulleted_list">打开条目，然后在条目工具栏中点击 <img height="25" :src="'/aras-images/ClaimOn.svg'" width="25"> 按钮。</p>
</li>
<li>
<p class="Bulleted_list">如果条目未被认领但处于编辑模式，请在条目工具栏中点击 <img height="25" :src="'/aras-images/done.jpg'" width="56"> 或 <img height="25" :src="'/aras-images/Discard.jpg'" width="60"> 按钮。</p>
</li>
</ul>
