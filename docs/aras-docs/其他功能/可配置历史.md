<h1>可配置的历史记录跟踪</h1>
<p class="Content_body">Aras Innovator 提供了跟踪条目历史记录的能力，可以记录自创建以来所做的所有更改。系统包含一组<i>动作</i>，可用于确定哪些事件会被记录在历史日志中。历史记录可以在条目和属性两个层级进行跟踪。例如，如果某个条目的名称属性被用户修改，系统不仅能跟踪到该条目被修改，还能记录名称属性的变更以及新旧值的对比。此外，历史记录跟踪利用了 Aras Innovator 内置的多语言功能，历史日志的标签和注释可以同时以多种语言记录（<i>有关配置 Innovator 处理多语言的更多信息，请参阅国际化章节</i>）。</p>
<p class="Content_body">需要注意的是，历史记录功能<i>默认不启用</i>，必须为每个需要跟踪历史的 ItemType 单独配置。这样可以避免不必要的数据给数据库造成负担。另外，如果现有的 ItemType 在条目实例数据<i>已存在</i>之后才启用历史记录，系统只会为每个条目实例记录未来发生的事件。类似地，如果现有的 ItemType 在条目实例数据<i>已存在</i>之后禁用了历史记录，未来的更改将不再跟踪历史事件。但是，在禁用之前为这些条目实例记录的所有历史数据<i>仍然保留在数据库中</i>，用户可以查看。</p>

<h2>历史记录模板：</h2>
<p class="Content_body">历史记录模板用于定义一组<b><i>动作</i></b>，这些动作将触发系统存储历史记录，以及该记录条目中包含的特定文本。Aras Innovator 提供了一个<b><i>默认</i></b>历史记录模板（如下所示），可用于为 ItemType 配置历史记录（注意：<b><i>默认</i></b>历史记录模板为只读）。此外，管理员也可以创建自定义模板。</p>

<h2>基于生命周期状态的历史记录</h2>
<p class="Content_body">在某些情况下，组织希望跟踪的历史记录取决于条目的生命周期状态。例如，当文档处于"初步"或"草稿"状态时，历史记录的更改不如文档处于"已发布"状态时重要。因此，Innovator 提供了为 ItemType 生命周期中的某些状态<b><i>覆盖</i></b>指定历史记录模板的功能。</p>
<!--?rh-list_start class="Numbered_list" start="1" mc="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">在生命周期编辑器表单中，在地图中选择一个状态。</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" mc="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<li class="Numbered">点击 <b><i>History Template</i></b> 字段中的 <img :src="'/aras-images/ellipses.jpg'"> 来选择<b><i>历史记录模板</i></b>。历史记录模板搜索对话框将出现。</li>
<li class="Numbered">选择要使用的生命周期地图。</li>
</ol>
