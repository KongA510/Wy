# Creating a Permission
<p class="Content_body">You can create Permissions and then assign them to ItemTypes, or you can create a Permission right from the Permissions tab in the ItemType.</p>
<p class="Content_body">To create a Permission:</p>
<ol>
<li class="Numbered">In the TOC, select <strong>Administration-&gt;Permissions-&gt;Create New Permissions</strong>. The following window appears:</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/permission1.png'"></p>
<ol start="2">
<li class="Numbered">Enter the permission name. Usually the name will be descriptive either of the permission type that is being created, or of the items to which the permission will be applied.</li>
<li class="Numbered">The next step is to specify the access rights. The access settings are described in the table below. Notice that the Can Add Permission as well as the TOC Access permission are not available within the Permission item. These two are set from the ItemType
directly. Refer to <a href="#" class="internal-doc-link">Can Add</a> and <a href="#" class="internal-doc-link">TOC Access</a> respectively to learn how to set these permissions.</li>
</ol>

<p class="Content_body">To enter a value for access:</p>
<ol>
<li class="Numbered">Notice the drop-down box next to the <strong>Actions </strong>field. You can select either <strong>Pick Related</strong> or <strong>Create Related</strong>. Choosing Pick Related brings up the Identity Search dialog box. Selecting Create Related enables
you to create a new identity. This example uses the Pick Related option.</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/searchid.png'"></p>
<ol start="2">
<li class="Numbered">Select an identity from the list and click the green arrow to add it to the Access tab. The selected Identity appears on the Access tab of&nbsp;the Permissions item. Select the privileges that you wish this identity to have by checking the boxes of the
corresponding privileges.</li>
<li class="Numbered">&nbsp;If you selected Create Related from the drop down box, a new empty line will be created for you. You can type in the name of a new identity, that you will be creating on a fly, and add the privileges that you want this new identity to have.</li>
</ol>
<p class="listindent1" style="margin-left: 1.0in; text-indent: -.25in;"><br>
<img :src="'/aras-images/mp2.jpg'"></p>
<ol start="4">
<li class="Numbered">Save, Unlock, and Close the Permission.</li>
</ol>
<p class="Content_body">You can set a permission to give different privileges to many different identities. Don't forget that identities can be groups and individuals, and if an individual identity is contained in more than one group identity, its privileges are cumulative.</p>
<p class="instructionfirst">To connect a permission to an ItemType:</p>
<p class="instructionlist" style="margin-left: .75in; text-indent: -.25in;">1.<span style="font-size: 7.0pt; font-family: 'Times New Roman';">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</span>&nbsp;From TOC, <span class="menuchoice"><span style="font-family: Arial;">Administration</span></span>, select <span class="menuchoice"><span style="font-family: Arial;">ItemTypes</span></span>
and find the ItemType to which you want to assign Permissions.</p>
<p class="instructionlist" style="margin-left: .75in; text-indent: -.25in;">2.<span style="font-size: 7.0pt; font-family: 'Times New Roman';">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</span>&nbsp;Open the ItemType for edit, and select the <span class="menuchoice"><span style="font-family: Arial;">Permissions</span></span> tab.</p>
<p class="instructionlist" style="margin-left: .75in; text-indent: -.25in;">3.<span style="font-size: 7.0pt; font-family: 'Times New Roman';">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</span>&nbsp;If you have already created a permission, then click the Select Items button <img :src="'/aras-images/selitems.jpg'">, select the appropriate permission from the
Permission dialog that appears and click the Return Selected icon <img :src="'/aras-images/returnselect.jpg'">.</p>
<p class="instructionlist" style="margin-left: .75in; text-indent: -.25in;">4.<span style="font-size: 7.0pt; font-family: 'Times New Roman';">&nbsp;&nbsp;&nbsp;&nbsp;</span>If you have not yet created a permission, you can create one on the fly, by choosing the&nbsp;<span class="menuchoice"><span style="font-family: Arial;">Create Item&nbsp;</span></span>
<span class="menuchoice"><span style="font-family: Arial; font-weight: normal;">icon <img :src="'/aras-images/createitem.jpg'">&nbsp;on the Permissions tab</span></span><span class="menuchoice"><span style="font-family: Arial; font-weight: normal;">.</span></span>
You will be guided through the same steps <a href="#CreatePermissions">outlined earlier</a>, except that the permission will already be assigned to the ItemType.</p>
<p class="instructionlist" style="margin-left: .75in; text-indent: -.25in;">6.<span style="font-size: 7.0pt; font-family: 'Times New Roman';">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</span>&nbsp;<span style="font-family: Arial;">Click&nbsp;&nbsp;<img :src="'/aras-images/done.jpg'">&nbsp;to save</span>&nbsp;the ItemType.</p>
