<h1>在工作流活动中使用团队/角色（仅限管理员）</h1>
<p class="Content_body"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman'; mso-bidi-font-weight: bold;">系统支持将团队身份组/角色指定为工作流映射活动的分配对象。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>这允许基于负责待完成工作的用户组（团队）进行动态工作流分配。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>当从工作流映射实例化工作流进程时，团队身份组或角色分配将被转换为团队或角色中每个成员的个人分配。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>例如，如果在某个特定条目的工作流映射活动中指定了团队身份组作为分配对象，则从该工作流映射创建的工作流进程将为团队的每个成员生成个人分配。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>根据工作流映射中定义的分配属性，将适用不同的规则（参见下方示例）。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>类似地，如果在某个特定条目的工作流映射活动中指定了团队角色（如团队经理）作为分配对象，则从该工作流映射创建的工作流进程将为团队中拥有该角色的每个成员生成个人分配（参见下方示例）。</span></p>

<!--?rh-list_end ?-->
<p class="Procedure_Title"><b style="font-weight: bold;"><u style="text-decoration: underline;"><span style="font-size: 12.0pt; line-height: 115%; font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">操作步骤：</span></u></b></p>
<!--?rh-list_start class="Numbered_list" start="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol class="Decimal">
<li class="Numbered"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">在现有工作流映射中查看某个活动（编辑模式），点击 <b style="mso-bidi-font-weight: normal;"><i style="mso-bidi-font-style: normal;">分配</i></b> 关系工具栏上的 <b><i>添加新关系</i></b> 按钮。系统将打开一个搜索对话框，其中列出了系统中现有的身份组。</span></li>
<li class="Numbered" style="margin-top: 4.5pt; line-height: normal; mso-list: l4 level1 lfo4;"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">使用蓝色搜索栏，筛选 <span class="GramE"><b style="mso-bidi-font-weight: normal;"><i style="mso-bidi-font-style: normal;">Is</i></b></span> <b style="mso-bidi-font-weight: normal;"><i style="mso-bidi-font-style: normal;">Alias=0</i></b> 且 <b style="mso-bidi-font-weight: normal;"><i style="mso-bidi-font-style: normal;">Classification=Team</i></b> 的身份组。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>这将返回可用的系统团队角色身份组，可直接用于活动分配。</span></li>
</ol>
