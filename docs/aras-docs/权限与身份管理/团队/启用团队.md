# Steps to Enable the Team Item for an Item Type (Administrators Only)
<!--?rh-list_start level="1" an="1" class="rl-p-Note" style="list-style: rh-list; 
list-style: rh-list;" ?-->
<p class="Note"><i style="font-style: italic; mso-bidi-font-style: normal;"><span style="font-family: Arial, sans-serif;">These steps describe exposing the ‘</span><span class="SpellE" style="font-family: Arial, sans-serif;">team_id</span><span style="font-family: Arial, sans-serif;">’ system property on a form for an ItemType.</span><span style="font-family: Arial, sans-serif; mso-spacerun: yes;">&nbsp;&nbsp;</span><span style="font-family: Arial, sans-serif;">They are generic and apply to any ItemType in the system.</span></i></p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<p class="Numbered" style="margin-top: 9.0pt; line-height: normal; mso-list: l8 level1 lfo10;"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">View the form (edit mode) for the ItemType to which you wish to provide users the ability to use the team item.</span></p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<p class="Numbered" style="margin-top: 9.0pt; margin-bottom: .0001pt; line-height: normal; mso-list: l8 level1 lfo10;"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">Add the ‘<span class="SpellE">team_id</span>’ system property to the form.</span>
</p>
