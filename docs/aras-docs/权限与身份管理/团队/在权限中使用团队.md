# 在权限中使用团队/角色（仅限管理员）
<p class="Content_body"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman'; mso-bidi-font-weight: bold;">系统支持将团队身份组/角色指定为权限定义的一部分。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>这使得能够根据负责该条目的团队成员来限制对条目的访问。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>例如，如果某个零件有一个包含多个成员的关联团队，其中某些用户可能需要进行更新等操作的访问权限，而团队中的其他用户只需能够查看该条目，不应拥有修改权限。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>使用团队身份组可以实现这种"动态"访问控制。</span></p>

<p class="Content_body"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman'; mso-bidi-font-weight: bold;">在上述示例中，"团队"的任何成员至少拥有"获取"访问权限。拥有"团队来宾"角色的成员同样拥有"获取"访问权限。<span style="mso-spacerun: yes;">&nbsp;&nbsp;</span>拥有"团队经理"角色的成员拥有"获取"、"更新"或"删除"权限。最后，拥有"团队成员"角色的团队成员同时拥有"获取"和"更新"权限。</span></p>

<p class="Note"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman'; mso-bidi-font-weight: bold;">请注意，必须为权限所适用的每个条目实例的 '<span class="SpellE">team_id</span>' 属性设置团队条目。这为系统在应用访问权限时提供了必要的团队信息。</span></p>
