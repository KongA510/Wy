# 创建团队（仅限管理员）
<div class="WordSection1">

<ol class="Decimal">
<li class="Content_body">在导航窗格中，选择 <strong>管理&gt;团队&gt;创建新团队</strong>。新团队窗口将显示。<br>
</li>
</ol>
<figure_indented> <img height="595" :src="'/aras-images/team1.jpg'" width="588"> </figure_indented>

<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->

<!--?rh-list_end ?-->

<ol class="Decimal" start="2">
<li class="Content_body_indented" style="font-family: Arial, sans-serif;"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">在 <b><i style="font-style: normal;">Name（名称）</i></b> 字段中输入团队名称（必填）。</span></li>
<li class="Content_body_indented" style="font-family: Arial, sans-serif;"> 在 <strong>Description（描述）</strong> 字段中输入团队的简要描述。<span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span></li>
<li class="Content_body_indented" style="font-family: Arial, sans-serif;"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">点击添加身份组按钮 <img :src="'/aras-images/addbreakdownitem.jpg'"></span>。 <span style="font-family: Arial, sans-serif; font-size: 11pt;"> </span><span style="font-family: Arial, sans-serif; font-size: 11pt;"> 身份组搜索对话框将出现。</span></li>
<figure_indented> <img height="339" :src="'/aras-images/selectid3.jpg'" width="819"></figure_indented>
<li>点击 <img :src="'/aras-images/searchicon.jpg'"> 查看身份组列表。<span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span></li>
<li><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">从搜索对话框中选择一个或多个身份组，然后点击 </span><img :src="'/aras-images/OK.jpg'"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">。</span></li>
<li><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">系统将所选的身份组记录作为新行填充到 <b><i style="font-style: normal;">团队成员</i></b> 关系网格中。</span> <span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';"></span></li>
<li class="Content_body" style="margin-top: 4.5pt; line-height: normal;"><span style="font-family: Arial, sans-serif; mso-fareast-font-family: 'Times New Roman';">要为团队成员分配角色（可选），请在关系网格中双击角色</span>字段并点击省略号按钮 <img :src="'/aras-images/ellipses.jpg'">。身份组搜索对话框将出现。<br>
<!--?rh-list_end ?-->
<p class="Note">注意：搜索已预过滤为 IS Alias='0' 且 Classification='Team'，用户无法更改。</p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->
</li>
</ol>
