<h1>更改您的密码</h1>
<p class="Content_body">要访问 Aras Innovator，系统中必须定义一个具有凭据（用户名和密码）的用户。您可以按照以下步骤更改密码：</p>


<ol style="list-style-type: decimal;">
<li class="Content_body">登录 Aras Innovator</li>
<li class="Content_body"> 点击窗口右上角的用户菜单按钮 <img :src="'/aras-images/Usermenu.jpg'">。将显示用户菜单。</li>
<li class="Content_body">选择<strong>首选项&gt;更改密码</strong>。将出现更改密码对话框。<br>
<br>
<br>
<img :src="'/aras-images/changepass.jpg'"></li>
<li class="Content_Body">在<strong>旧密码</strong>字段中输入当前密码。</li>
<li class="Content_Body">在<b>新密码</b>字段中输入新密码。在<strong>确认新密码</strong>字段中重新输入新密码以进行确认。</li>
<li class="Content_body">点击<b>确定</b>。</li>
</ol>

</div>
