# 管理用户
<p class="Content_body">Aras Innovator 中的访问权限通过定义登录用户和身份组来进行管理。登录用户是指在 Aras Innovator 应用中拥有登录权限的独立个体。<span style="mso-spacerun: yes;"> </span>每个登录用户都属于一个通过别名分配定义的唯一用户身份组。<span style="mso-spacerun: yes;"> </span>用户身份组随后被分配访问权限，并可归入组身份组中。<span style="mso-spacerun: yes;"> </span>组身份组可由个体身份组或其他组身份组组成，每个组身份组可拥有自己的一组访问权限。<span style="mso-spacerun: yes;"> </span>这些身份组的设计理念是定义一种成员结构，用于控制和管理访问权限。</p>

<p class="Content_body">最佳实践：我们建议按照类似构建公司组织架构图的方式来设置用户身份组。<span style="mso-spacerun: yes;"> </span>以下是使此过程更简便的步骤列表。</p>
<ol class="Numbered_list">
<li>为顶层部门创建身份组，例如：工程部、销售部和市场部。</li>
<li>为每个顶层部门创建下属子部门。<span style="mso-spacerun: yes;"> </span>例如，工程部下可设有：开发部、技术支持部和质量保证部。技术支持部又可进一步包含：客户支持、文档和培训。<span style="mso-spacerun: yes;"> </span>确保将下属子部门作为成员添加到其各自的组身份组中。</li>
<li>部门结构搭建完成后，创建个体用户身份组并将其添加到各自的部门中。<span style="mso-spacerun: yes;"> </span>在 Innovator 中，一个用户身份组可以属于多个组。</li>
</ol>
