# 创建工作流映射
<p class="Content_body">创建工作流映射包括创建活动并用路径将它们连接起来。在这里，您将学习如何打开一个新的工作流映射，以及如何创建活动和路径来填充它。</p>
<p class="Procedure_Title">打开一个新的工作流映射表单：</p>
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">从导航窗格中，选择 管理&gt;工作流映射。出现以下菜单：</li>
</ol>
<p class="Figure_indented" style="margin-left: 50px;"><img :src="'/aras-images/workflowmap.jpg'" style=""></p>
<ol start="2">
<li class="Numbered">点击 <strong>创建新工作流映射</strong>。一个空白的工作流映射窗口随即显示。</li>
</ol>
<p class="Figure_indented" style="margin-left: 50px;"><img :src="'/aras-images/workflowmapempty.jpg'"></p>

<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Content_body">工作流映射的头部属性如下：<strong><span class="MenuChoice"></span></strong></p>
<ul style="list-style-type: disc;">
<li class="Numbered" style="margin-left: 50px;"><strong><span class="MenuChoice"></span></strong><strong><span class="MenuChoice">名称</span> </strong>- 工作流映射的名称<strong></strong></li>
<li class="Numbered" style="margin-left: 50px;"><strong>标签 </strong>- 显示在条目上的工作流映射名称。<span class="MenuChoice"></span></li>
<li class="Numbered" style="margin-left: 50px;"><strong><span class="MenuChoice">描述</span> </strong>- 映射中描述的流程说明。</li>
<li class="Numbered" style="margin-left: 50px;"><strong>流程负责人</strong> - 负责此流程的身份组，通常是一个组身份。
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="2" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
</ul>

<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<p class="Content_body">工作流映射本身有两个选项卡：</p>

<p class="Content_body_indented"><strong>活动</strong>- 此选项卡将列出在映射中创建的所有活动及其部分属性。创建、删除和修改这些活动的界面通过图形化设计器完成。此选项卡上的信息仅为摘要。</p>
<p class="Content_body_indented"><strong>流程变量</strong> - 需要作为整体添加到映射中的变量列表。这些变量可以作为循环的属性通过编程方式访问。</p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="2" style="list-style: rh-list;
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="2" style="list-style: rh-list;
list-style: rh-list;" ?-->

<!--?rh-list_end ?-->
<p class="Procedure_Title">创建活动或节点</p>
<!--?rh-list_start class="Numbered_list" start="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<ol>
<li class="Numbered">右键点击映射背景，然后从弹出菜单中选择 <strong><span class="MenuChoice">添加活动</span></strong>。一个新节点将放置在映射上并自动被选中。</li>
</ol>

<p class="Content_body_indented"><img :src="'/aras-images/addactivity.jpg'"></p>

list-style: rh-list;" ?-->

<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->


<ol start="2">
<li class="Numbered" style="margin-left: 50px;">填写头部属性和选项卡，详见 <a href="#" class="internal-doc-link">工作流活动</a>。</li>
</ol>
<!--?rh-list_end ?-->


## 
<p class="Procedure_Title">创建新的工作流路径</p>
<!--?rh-list_start class="Numbered_list" start="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">右键点击您希望路径起点的活动。</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<li class="Numbered">从弹出菜单中选择 <strong><span class="MenuChoice">添加路径</span> </strong>。路径矢量线将连接到鼠标。指向路径终点的活动，然后点击。</li>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<li class="Numbered">您应该能看到路径连接了所选的活动。再次点击路径以选中它，注意下方两个窗格中的属性发生了变化：</li>
</ol>
<!--?rh-list_end ?-->
<p class="Content_body_indented"><img :src="'/aras-images/workflowmap2.jpg'"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->

<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Content_body_indented">"活动"选项卡列出与该映射关联的工作流活动。与活动关联的优先级编号表示活动的顺序。"流程变量"选项卡使您能够向工作流添加上下文信息。</p>
<p class="Content_body_indented">按照 <a href="#" class="internal-doc-link">工作流路径</a> 中的描述和图示填写此路径的属性。</p>
<!--?rh-list_end ?-->
