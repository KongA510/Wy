---
title: 将工作流附加到条目
---

<div>
<h1>将工作流附加到条目</h1>
<p class="Content_body">目前，通过在 ItemType（物料类型）定义的工作流选项卡中指定工作流，可以将工作流附加到条目。</p>
<p class="Content_body_indented"><img height="538" :src="'/aras-images/AttachWork.jpg'" width="899"></p>
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->

<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol style="list-style-type: decimal;">
<li class="Numbered" style="margin-left: 50px;">在导航窗格中，选择<span class="MenuChoice" style="font-weight: bold;">管理 --&gt; ItemType（物料类型）</span>，选择要添加工作流的 ItemType（物料类型），然后将其打开以进行编辑。<br>
<br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Numbered" style="margin-left: 50px;">选择<strong>工作流</strong>选项卡。
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Numbered" style="margin-left: 50px;">单击<strong>选择条目</strong>按钮 <img :src="'/aras-images/selitems.jpg'">。将出现工作流搜索对话框。选择要添加的工作流，然后单击<strong>返回已选</strong>按钮 <img alt="" border="0" :src="'/aras-images/image916.gif'" style="border: none;">。<br>
<br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</li>
<li class="Numbered" style="margin-left: 50px;">如果您希望在创建条目的新实例时自动启动此工作流，请选中"默认"复选框。</li>
</ol>
<!--?rh-list_end ?-->
<p class="Content_body">与该条目关联的所有工作流都必须列在此选项卡上。例如，如果您有一个用于默认工作流某个活动的子工作流，它必须列在此处（但不能标记为默认）。如果您有一个希望通过编程方式激活的工作流，也必须在此处列出，并取消选中"默认"复选框。</p>


</div>
