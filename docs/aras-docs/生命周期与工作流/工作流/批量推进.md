# 关于批量晋级
<p class="Content_body">Aras Innovator 中的批量晋级功能允许用户从搜索结果网格中选择多个条目，然后通过工具栏或上下文下拉菜单中的晋级图标一次性晋级多个条目。</p>
<p class="Content_body">批量晋级窗口以新选项卡（选项卡模式）或弹出窗口（标准模式）的形式出现。</p>
<p class="Note">注意：<br> 无论您选择的条目类型如何，晋级功能都会被启用。验证检查要到批量晋级窗口出现后才会执行。<br>
<br> 使用批量晋级时，您只能选择相同 ItemType（物料类型）的多个条目。</p>
## 批量晋级窗口
<p class="Content_body"><img :src="'/aras-images/Masspromote3.jpg'"></p>
<p class="Content_body">批量晋级窗口由横幅、设置面板和网格组成。横幅显示所选条目的数量及其 ItemType（物料类型）。设置面板显示以下模块：</p>
<ul style="list-style: disc;">
<li>
<p class="Bulleted_list"><span style="font-weight: bold;"><a href="Mass_Promote_-_Settings_Modules.htm#Selecting_a_Life_Cycle_Map">生命周期映射</a></span> 仅当网格中显示的条目不共享同一生命周期映射时才会出现。您需要为您要晋级的条目选择一个生命周期。系统会将没有关联生命周期映射的条目视为无效条目。</p>
</li>
<li>
<p class="Bulleted_list"><span style="font-weight: bold;"><a href="Mass_Promote_-_Settings_Modules.htm#Selecting_a_Target_State">目标状态</a></span> 允许您为正在晋级的条目选择目标状态。条目将晋级到您所选择的状态。</p>
</li>
<li>
<p class="Bulleted_list"><span style="font-weight: bold;"><a href="Mass_Promote_-_Settings_Modules.htm#Entering_Comments">备注</a></span> 仅当一个或多个条目关联的生命周期转换启用了备注功能时才会出现。</p>
</li>
<li>
<p class="Bulleted_list"><span style="font-weight: bold;"><a href="Mass_Promote_-_Settings_Modules.htm#Resolving_Invalid_Items">无效条目</a></span> 仅当在所选条目列表中检测到一个或多个无效条目时才会出现。</p>
</li>
<li>
<p class="Bulleted_list"><span style="font-weight: bold;"><a href="Mass_Promote_-_Settings_Modules.htm#Promoting_Items">执行</a></span> 在条目之间的冲突解决后出现。</p>
</li>
<li>
<p class="Bulleted_list"><span style="font-weight: bold;"><a href="Mass_Promote_-_Settings_Modules.htm#Using_the_Status_Module">状态</a></span> 显示当前晋级状态。</p>
</li>
</ul>
