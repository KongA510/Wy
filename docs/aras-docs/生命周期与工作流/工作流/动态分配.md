# 动态分配
<p class="Procedure_Title">动态分配必须在工作流映射中设置</p>
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Bulleted_list" style="margin-left: 50px;">选择您希望实施动态分配的任何活动的管理员。只有管理员才能更改工作流流程的被分配人</p>
<!--?rh-list_end ?--><!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Bulleted_list" style="margin-left: 50px;">选择同一活动的角色，角色是一个身份组；只有此身份组的成员才能被分配到该活动</p>
<!--?rh-list_end ?--><!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Bulleted_list" style="margin-left: 50px;">工作流映射中所有需要动态分配的活动都必须设置管理员和角色。</p>
