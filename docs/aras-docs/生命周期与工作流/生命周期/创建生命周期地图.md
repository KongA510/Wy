<h1>创建生命周期地图</h1>
<p class="Content_body">生命周期地图可以独立于任何 ItemType 创建，之后再将其关联到 ItemType。实际上，多个 ItemType 可以使用同一个生命周期地图。此外，一个 ItemType 可以包含多个生命周期地图，这些地图与 ItemType 的分类层级相关联。当为 ItemType 创建条目实例时，Innovator 会根据条目的初始分类选择适当的生命周期地图。当更新条目实例时，Innovator 会检查分类属性是否有任何更改。如果条目的分类已更改为允许的类别，且该类别具有不同的生命周期地图，而条目当前的生命周期状态仍在"起始状态"，则 Innovator 将把条目的生命周期设置为新分类指定的生命周期。如果对现有条目实例的分类进行了更改，而该条目的生命周期<i>不</i>在"起始状态"，则 Innovator 将拒绝分类更改，以避免干扰生命周期的正常推进。如有需要，可以对生命周期地图进行建模，允许将条目提升回起始状态，以便普通用户可以执行分类更改。</p>
<p class="Procedure_Title">创建生命周期地图：</p>




<ol>
<li class="Numbered">在导航窗格中，选择 <strong>管理&gt;生命周期地图</strong>。将显示以下菜单：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/Class_Based_LC/assets/images/lifecyclemenu.jpg'"><img :src="'/aras-images/lifecyclemenu.jpg'"></p>
<ol start="2">
<li class="Numbered">点击 <strong>创建新生命周期地图</strong>。空白的生命周期地图将显示：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/Class_Based_LC/assets/images/blanklifecycle.jpg'"><img :src="'/aras-images/newlifecycle.jpg'"></p>
<ol start="3">
<li class="Numbered">填写生命周期地图属性：
<ul>
<li class="Bulleted_list">Name（名称） <span style="font-size: 11pt;">- 地图的名称</span></li>
<li class="Bulleted_list">Description（描述）- 地图的描述</li>
</ul>
</li>
</ol>
<ol start="4">
<li class="Numbered">右键点击地图画布上的任意位置，从弹出菜单中选择 <strong>添加状态</strong> 来创建新状态。新状态将被创建并默认处于选中状态。每个生命周期状态具有以下属性：</li>
</ol>

<h4>创建转换</h4>
