<h1>在生命周期中晋级条目</h1>
<p class="Content_body">生命周期映射由管理员定义，并与 ItemType（物料类型）关联。这些映射为条目在不同生命周期状态之间的推进提供规则。一个条目同一时间只能处于一个状态，任何变更为新状态的操作称为晋级。</p>
<!--?rh-list_start level="1" an="1" class="rl-p-Note" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Note">如果您尝试晋级一个没有所需访问权限的条目，将显示错误消息"无可用的晋级"。</p>
<!--?rh-list_end ?-->
<p class="Procedure_Title">将条目晋级到新的生命周期状态</p>
<!--?rh-list_start class="Numbered_list" style="font-size: 11pt; list-style: rh-list;
list-style: rh-list;" ?-->

<ol style="list-style-type: decimal;">
<li class="Numbered">登录 Aras Innovator。</li>
<li class="Numbered">从目录导航到目标条目。以零件 ItemType（物料类型）为例。</li>
<li class="Numbered">导航到 <span class="Bold">设计 --&gt; 零件</span>。</li>
<li class="Numbered">从主网格中选择要晋级的条目。</li>
<li class="Numbered">要晋级该条目，可以使用以下方式之一：</li>
</ol>
<ol style="list-style-type: lower-alpha;">
<li class="Bulleted_list" style="margin-left: 40px;">单击主工具栏上的 <img alt="" class="Image" :src="'/aras-images/Main_toolbar_promote_icon.jpg'" style="cursor: nesw-resize;">。</li>
<li class="Bulleted_list" style="margin-left: 40px;">使用鼠标右键打开上下文菜单，然后选择<span class="Bold">晋级</span>。
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="2" style="font-size: 11pt; list-style: rh-list;
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->
</li>
<li class="Bulleted_list" style="margin-left: 40px;">或者，您可以打开零件条目窗口，然后单击条目工具栏上的 <img alt="" class="Image" :src="'/aras-images/Main_toolbar_promote_icon.jpg'">，或从条目菜单中选择<span class="Bold">编辑 --&gt; 晋级</span>。</li>
</ol>
<!--?rh-list_end ?-->

<p class="Note_indented">注意：您无法晋级已领取的条目。要晋级条目，该条目必须处于未领取状态。工具栏上的晋级按钮或菜单中的晋级选项仅对未领取的条目启用。</p>
<p class="Content_body">将出现<span class="Bold">晋级</span>对话框，其中列出了该条目可以晋级到的状态列表。</p>
