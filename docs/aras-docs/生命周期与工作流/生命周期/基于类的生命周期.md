<h1>创建生命周期映射</h1>
<p class="Content_body">生命周期映射可以独立于任何 ItemType（物料类型）单独创建，之后再将其关联到对应的 ItemType（物料类型）。事实上，多个 ItemType（物料类型）可以共用同一个生命周期映射。此外，一个 ItemType（物料类型）可以包含多个生命周期映射，这些映射与该 ItemType（物料类型）的类层级结构相关联。当为某个 ItemType（物料类型）创建条目实例时，Aras Innovator 会根据条目的初始分类选择合适的生命周期映射。当更新条目实例时，Aras Innovator 会检查分类属性是否发生变化。如果条目的类已更改为允许的类，并且该类有不同的生命周期映射，且条目当前的生命周期状态仍处于"起始状态"，则 Aras Innovator 会将该条目的生命周期设置为新分类指定的生命周期。如果对已有条目实例的分类进行更改，且该条目的生命周期<i>不</i>处于"起始状态"，则 Aras Innovator 将拒绝分类更改，以避免干扰生命周期的正常推进流程。如有需要，可以对生命周期映射进行建模，使其允许回退到起始状态，从而使普通用户可以执行类更改操作。</p>
<p class="Procedure_Title">创建生命周期映射：</p>




<ol>
<li class="Numbered">在导航窗格中，选择 <strong>管理 &gt; 生命周期映射</strong>。出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/lifecyclemenu.jpg'"></p>
<ol start="2">
<li class="Numbered">点击 <strong>创建新生命周期映射</strong>。出现一个空白的生命周期映射：</li>
</ol>
<p class="Figure_indented"><img height="322" :src="'/aras-images/lifecycle.jpg'" width="852"></p>
<ol start="3">
<li class="Numbered">填写生命周期映射属性：
<ul>
<li class="Bulleted_list">名称 - 映射的名称</li>
<li class="Bulleted_list">描述 - 映射的描述信息</li>
</ul>
</li>
<li class="Numbered">通过在映射画布上任意位置右键单击并从弹出菜单中选择 <strong>添加状态</strong> 来创建新的状态。新状态默认处于选中状态。每个生命周期状态具有以下属性：</li>
</ol>

<h4>创建转换</h4>
<ol>
<li class="Numbered">右键单击您希望创建转换的起始状态。<br>
</li>
<li class="Numbered">从弹出菜单中选择 <strong><span class="menuchoice" style="font-family: Arial, sans-serif;">添加转换</span></strong>。将从指定状态创建一个转换并连接到鼠标。将鼠标拖动到您想要连接的状态，然后单击以完成转换的连接。</li>
