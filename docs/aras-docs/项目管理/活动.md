<h1>活动/里程碑</h1>
<p>活动（或 Activity2）是项目计划的基本构建单元。一个活动包含与之关联的任务列表、完成这些任务的时间段或持续时间，以及需要提交的交付物列表。里程碑是一种特殊活动，持续时间为零。除了项目计划选项卡中显示的信息外，每个活动还有一个详细对话框。让我们来看一个设计项目及其活动树：</p>
<p><img height="604" :src="'/aras-images/doordesign1.jpg'" width="856"></p>

<p>请注意高亮显示的活动"需求分析"。我们将以此活动作为示例。</p>
<p>要更详细地查看活动，您可以从右键弹出菜单中选择"查看/编辑所选条目"，或点击"查看/编辑所选条目"图标 <img :src="'/aras-images/viewedit.jpg'">。此时将显示 Activity2 详细对话框。请注意，此对话框没有典型的编辑图标。此对话框上更改的所有信息在对话框关闭时会自动保存。此对话框上的信息与项目计划选项卡中的活动信息相关联。无论在何处更改信息，两处都会同步更新。</p>
<p class="Content_body_indented"><img height="582" :src="'/aras-images/activity2.jpg'" width="728"></p>

<p class="Content_body">让我们来看看此对话框的属性和选项卡。</p>
<p class="Content_body">此对话框的头部包含三个区域：</p>
<p><strong><span>供项目经理使用</span></strong> - 以下所有属性由本项目的项目经理身份填写：</p>
<ol class="LowerAlpha">
<li><span class="MenuChoice">
<!--?rh-ignored text="Deliv" ?-->交付物必需</span> - 布尔值，指示活动是否需要交付物才能完成。如果勾选，则在负责人附加交付物之前，活动无法完成。</li>
<li><span class="MenuChoice">
<!--?rh-ignored text="Deliv" ?-->交付物类型</span> - 交付物的 ItemType（物料类型）。此选项仅在活动需要交付物时适用，但即使在这种情况下，指定交付物类型也不是必需的。</li>
<li><span class="MenuChoice">描述</span> - 活动的描述</li>
<li><span class="MenuChoice">是否必需</span> - 布尔值，指示此活动是否为必需。当项目从模板创建（模板中可以将活动标记为必需）时适用。对于必需活动，复选框将被勾选，且该属性为只读（由模板设定）。</li>
<li><span class="MenuChoice">工作量估算</span> - 完成活动的估计工时数。</li>
<li><span class="MenuChoice">预计持续时间</span> - 活动的持续时间，从项目计划选项卡传输至此。</li>
<li><span class="MenuChoice">计划截止日期</span> - 活动的计划截止日期。项目经理可以在最早完成日期（Date Ef）和最晚完成日期（Date Lf）之间选择一个日期，但计划开始日期加上持续时间必须等于截止日期。</li>
<li><span class="MenuChoice">计划开始日期</span> - 活动的计划开始日期。项目经理可以在最早开始日期（Date Es）和最晚开始日期（Date Ls）之间选择一个日期，这两个日期由计划员计算。当这两个日期相同时，项目经理没有选择余地。</li>
<li><span class="MenuChoice">项目经理</span> - 项目的管理者</li>
<li><span class="MenuChoice">名称</span> - 活动的名称</li>
<li><span class="MenuChoice">系统管理</span> - 这些属性由 Aras Innovator 管理。此处显示的值均为只读。</li>
<li><span class="MenuChoice">状态</span> - 活动的状态，可以是以下两种之一：活动或待定。当项目被推进到活动状态，且活动的计划开始日期为今天或更早时，即达到活动状态。</li>
<li><span class="MenuChoice">状态指示</span> - 活动的红绿灯指示器，以及所有底层任务汇总的完成百分比。
<ul class="Disc">
<li><span class="MenuChoice">无颜色</span> - 活动处于待定状态，意味着计划开始日期尚未到达</li>
<li><span class="MenuChoice">绿色</span> - 活动处于活动状态（即开始日期为今天或更早），且今天与活动计划完成日期之间的天数大于 7 天。</li>
<li><span class="MenuChoice">黄色</span> - 活动处于活动状态（即开始日期为今天或更早），且今天与活动计划完成日期之间的天数小于等于 6 天但大于等于 1 天。</li>
<li><span class="MenuChoice">红色</span> - 活动处于活动状态（即开始日期为今天或更早），且活动的计划完成日期为今天或更早。</li>
<li style="counter-set: item1 1;"><span class="MenuChoice">激活日期</span> - 此活动启动的日期。可能早于计划日期启动。</li>
<li><span class="MenuChoice">原始截止日期</span> - 原始截止日期，后续可用于跟踪和度量中以衡量计划和预测项目成功的准确性。</li>
<li><span class="MenuChoice">最早开始日期 (Date Es)</span> - 由日期传播算法计算的最早可能开始日期。</li>
<li><span class="MenuChoice">最晚开始日期 (Date Ls)</span> - 由日期传播算法计算的最晚可能开始日期。</li>
<li><span class="MenuChoice">最早完成日期 (Date Ef)</span> - 由日期传播算法计算的最早可能完成日期。</li>
<li><span class="MenuChoice">最晚完成日期 (Date Lf)</span> - 由日期传播算法计算的最晚可能完成日期。</li>
<li><span class="MenuChoice">供分配人使用</span> - 由分配完成活动的身份组控制的属性。这些属性与<a href="#" class="internal-doc-link">活动完成工作表</a>中输入的值相对应。因此，当分配人更新工作表时，新值也会在此处反映。
<ul>
<li><span class="MenuChoice">实际开始日期</span> - 活动实际开始的日期。</li>
<li><span class="MenuChoice">实际截止日期</span> - 活动实际完成的日期。</li>
<li><span class="MenuChoice">完成</span> - 分配人选择更新此信息时的完成百分比。</li>
</ul>
</li>
</ul>
</li>
</ol>
