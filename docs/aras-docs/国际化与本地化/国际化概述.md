# 关于 Innovator 的国际化与本地化
<p class="Content_body">从 9.0 版本开始，Innovator 通过以下功能支持国际化和本地化：</p>
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<ul style="list-style-type: disc;">
<li class="Bulleted_list" style="margin-left: 50px;">
<p class="Bulleted_list">英语为默认语言
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</p>
</li>
<li class="Bulleted_list" style="margin-left: 50px;">
<p class="Bulleted_list">可以使用语言包创建或添加其他语言</p>
</li>
<li class="Bulleted_list" style="margin-left: 50px;">
<p class="Bulleted_list">多语言字符串数据类型用于以可选语言显示值</p>
</li>
<li class="Bulleted_list" style="margin-left: 50px;">
<p class="Bulleted_list">语言包会根据客户端的区域设置显示相应的菜单、标签和值，使用户能够使用已安装的语言导航和使用 Innovator</p>
</li>
<li class="Bulleted_list" style="margin-left: 50px;">
<p class="Bulleted_list">Innovator 客户端会根据客户端的区域设置自动格式化日期、时间和小数
<!--?rh-list_end ?-->
<!--?rh-list_start class="Bullet_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</p>
</li>
<li class="Bulleted_list" style="margin-left: 50px;">
<p class="Bulleted_list">如果设置了公司时区，Innovator 客户端将显示公司时间，所有日期和时间均以公司时间显示</p>
</li>
</ul>

## <b style="font-weight: bold;">新增 ItemType</b>
### <b style="font-weight: bold;">区域设置（Locale）</b>
<p class="Content_body">Innovator 的区域设置 ItemType 代表 Innovator 实例支持的区域设置。它映射到 Windows 区域设置，例如英语（美国）或德语（德国），并具有标识该区域设置所使用的 Innovator 语言及其在 Innovator 中的显示方式的属性。</p>

<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->

<!--?rh-list_end ?-->
### <b style="font-weight: bold;">语言（Language）</b>
<p class="Content_body">Innovator 的语言 ItemType 代表 Innovator 实例支持的语言。安装后，Innovator 仅包含默认语言——英语。管理员可以添加其他语言。</p>

### <b style="font-weight: bold;">新增数据类型</b>
#### <b><span style="font-weight: bold;">多语言</span>字符串</b>
<p class="Content_body">多语言字符串类型的属性可以为 Innovator 中安装的每种语言设置一个值。</p>
<p class="Content_body">多语言字符串的主要用途是使用户能够以多种语言导航和使用 Innovator。它们在 Innovator 中用于菜单、表单和网格上的标签以及列表值。</p>
<p class="Content_body">多语言字符串不能标记为必填或设置默认值。</p>
<p class="Content_body">因此，多语言字符串主要用于元数据（关于数据的数据）。虽然可以将多语言字符串用于实例数据，但这样做需要在业务流程中提供多语言值。</p>
#### 编辑多语言字符串
<p class="Content_body">在使用多语言字符串且数据库中安装了其他语言的地方，具有更新权限的用户可以使用多语言编辑对话框编辑任何语言的值。</p>
<p class="Content_body_indented"><img :src="'/aras-images/multilingualentry2.png'"></p>

### <b style="font-weight: bold;">客户端设置</b>
<p class="Content_body">Innovator 客户端使用两个标准的 Windows 设置。这些设置会在安装 Windows 时自动设置，并可由企业 IT 团队控制或由 Windows 用户个人设置。</p>
### <b style="font-weight: bold;">区域设置语言环境</b>
<p class="Content_body">打开控制面板，选择"时钟、语言和区域"：</p>
<p class="Content_body"><img :src="'/aras-images/reglang.jpg'"></p>
