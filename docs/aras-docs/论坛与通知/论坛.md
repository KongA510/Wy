<h1 style="font-weight: bold;">论坛</h1>
<p class="Content_body" style="font-weight: normal;">论坛允许就任何话题进行安全的社交讨论。论坛包含条目和已保存的搜索。<span style="font-weight: normal;">论坛不包含其他论坛，但包含针对特定话题的讨论。</span></p>
