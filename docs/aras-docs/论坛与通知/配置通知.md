# 配置通知
<p class="Content_body">通知允许将电子邮件消息配置为从选定身份组自动发送到选定身份组。通知由选定事件触发，例如"激活时"（当活动变为活动状态时）或"委托时"（当活动被委托时）。通知还可以包含当前实例数据，例如与此工作流关联的 ItemType（物料类型）实例的任何指定属性的值。您还可以通过提供从数据库检索信息的查询来包含来自其他条目的任何其他实例数据，例如关联条目的某些属性，或活动本身的名称。以下是活动的"通知"选项卡的示例。</p>

## <a id="variables" name="variables"></a>在电子邮件文本中使用变量
<p class="Content_body">您可以在电子邮件文本中使用变量来标识确切的条目及其属性值，从而使电子邮件消息更加具体。让我们看一下工作流条目的 XML，它看起来大致如下：</p>
<p class="Code"><span class="Code"> &lt;
<!--?rh-glo_start class="glossterm" ?=""-->AML&gt;</span></p>

<p class="Code"><span class="Code">   <item_number>ECR-1000</item_number></span></p>
<p class="Code"><span class="Code">   <state>Released</state></span></p>


<p class="Code"><span class="Code">   <name>Vote on me</name></span></p>

<p class="Code"><span class="Code">
<!--<?rh-glo_start class="glossterm" ?=""-->AML&gt;</span></p>
<p class="Content_body">因此，如果我们想访问 ECR 的 state 属性的值，应编写：</p>
<p class="Code_Sample"><span class="Code">${Item[@type='ECR']/state}</span></p>
<p class="Content_body">如果我们想访问活动的名称，应编写：</p>
<p class="Code"><span class="Code">${Item[@type='Activity']/name}</span></p>
<p class="Content_body">因此，一般而言，访问工作流消息中条目属性值的格式为：</p>
<p class="Code"><span class="Code">${Item[@type='ItemType_name']/property_name}</span></p>
<p class="Content_body">其中 ItemType_name 是您要访问其属性值的 ItemType（物料类型）的名称，property_name 是属性的名称。</p>
