<h1>关于查看器</h1>
<p class="Content_body"><span style="font-weight: bold;">查看器</span>定义了在 Web 浏览器中启动的用于查看存储在 Innovator 保险库中的文件的应用程序。查看器 URL 链接到一个 HTML 文件，该文件包含查看器的启动指令。一个<span style="font-weight: bold;">查看器</span>可以通过<span style="font-weight: bold;">使用...查看</span>关系选项卡关联到 FileType（文件类型）条目。</p>
<p class="Content_body">当打开一个文件进行查看时，<span style="font-weight: bold;">查看器</span>会被启动，并将文件 URL 作为输入传递。当没有<span style="font-weight: bold;">查看器</span>与 FileType（文件类型）关联时，Web 浏览器将尝试使用 MIME 类型或插件控制的关联方式来打开文件。</p>

</div>
