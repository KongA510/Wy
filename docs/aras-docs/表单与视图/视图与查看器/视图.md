# 视图
<p class="Content_body">视图是 ItemType（物料类型）与表单之间的关系。</p>
<!--?rh-list_start class="Bullet_list" style="list-style: rh-list; list-style: rh-list;" ?-->
<p class="Bulleted_list">可以为添加、查看和编辑操作显示不同的替代表单，这在"类型"列中选择。"默认"表示同时用于查看和编辑不同身份组，在"身份组"列中选择。当 ItemType 使用<a href="#" class="internal-doc-link">类结构</a>时，替代表单可用于分类。如果某个特定场景有多个符合条件的表单，将显示优先级最高的表单。</p>
