<div>
<h1>删除表单</h1>
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">从导航窗格中选择<strong>Administration&gt;Forms&gt;Search Forms</strong>。搜索网格将出现。</li>
<li class="Numbered">点击<img :src="'/aras-images/searchbutton.jpg'">查看表单列表。</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/formlist.jpg'"><br>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</p>
<ol start="3">
<li class="Numbered">右键点击网格中的表单行以查看上下文菜单。</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/contextmenu1.jpg'"></p>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->

<ol start="4">
<li class="Numbered">点击<b>Delete All Versions</b>。将出现类似以下的对话框：<br>
<br>
<img :src="'/aras-images/delmess.jpg'"></li>
</ol>
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol start="5">
<li class="Numbered">点击<strong>OK</strong>。</li>
</ol>
<!--?rh-list_end ?-->
<!--?rh-list_start level="1" an="1" class="rl-p-Note" style="font-size: 11pt;
list-style: rh-list; list-style: rh-list;" ?-->
<p class="Note_indented">注意：如果在弹出窗口之后出现错误消息，表示该条目未被删除。错误消息中会出现对应ItemType（物料类型）的属性名称，格式为[itemtype_name property_name}，该属性必须从ItemType（物料类型）中删除。</p>
