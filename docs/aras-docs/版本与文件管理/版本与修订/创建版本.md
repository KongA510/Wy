# 创建版本
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<p class="Content_body">当您创建或编辑条目时，系统会为该条目创建一个版本。在本示例中，我们将使用零件 J-100002。</p>
<ol>
<li class="Numbered">在导航窗格中，选择 <strong>设计&gt;零件</strong>。出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/partmenu.jpg'"></p>


<ol start="2">
<li class="Numbered">点击 <strong>搜索零件</strong>。<b>零件</b>搜索网格随即显示。</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/partgrid.jpg'"></p>


<ol start="4">
<li class="Numbered">右键点击 J-100002 行，然后在出现的上下文菜单中点击 <strong>版本</strong>。条目版本弹出框随即显示。</li>
</ol>


<p class="Figure_indented"><img alt="" :src="'/aras-images/itemversion.jpg'"></p>
<ol start="5">
<li class="Numbered">点击 <img :src="'/aras-images/edit.jpg'"> 以打开条目进行编辑。</li>
<li class="Numbered">在 BOM 选项卡上，点击 <strong>选择条目</strong> 按钮 <img :src="'/aras-images/selitems.jpg'">。零件搜索对话框随即显示。</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/partsearch1.jpg'"></p>
<ol start="7">
<li class="Numbered">选择要添加到 BOM 的零件，然后点击返回选中按钮 <img :src="'/aras-images/returnselect.jpg'">。</li>
</ol>

<ol start="8">
<li class="Numbered">点击 <img :src="'/aras-images/done.jpg'"> 以保存并关闭条目。</li>
<li class="Numbered">点击导航按钮 <img :src="'/aras-images/navigate.jpg'">，然后从上下文菜单中选择"版本"。条目版本弹出框将显示新版本信息。</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/itemver2.jpg'"></p>
