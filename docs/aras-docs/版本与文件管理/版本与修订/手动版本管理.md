<h1>手动版本</h1>
<p class="Content_body"><span style="font-weight: bold;">手动版本</span>是一项管理员可以对条目执行的可选功能。当管理员定义一个 ItemType（物料类型）并将其标记为可生成版本时，创建新版本的操作可由系统自动执行、通过自定义业务逻辑执行，或由用户手动执行。当启用<span style="font-weight: bold;">手动版本控制</span>时，将提供一个"版本"菜单选项。通过选择此菜单选项，即可创建该条目的新版本。</p>
<!--?rh-list_start level="1" an="1" class="rl-p-Note" style="font-size: 11pt;
list-style: rh-list; list-style: rh-list;" ?-->
<p class="Note"><span style="font-weight: bold;">手动版本控制</span>只能对当前处于未锁定状态的条目执行。</p>
