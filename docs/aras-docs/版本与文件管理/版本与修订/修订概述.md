# 关于修订版
<p class="Content_body">修订版是一系列用于标识可版本化条目主要修订版本的符号列表。所有可版本化的条目会自动获得一个世代编号。每当对条目进行更改时，该编号会自动递增；更改操作包括锁定条目、更新条目，然后保存并解锁条目。修订版，或条目中称为"Major Rev"的属性，仅在条目到达其已发布的生命周期状态并且再次更新时才会递增。要了解更多关于此概念的信息，请参阅生命周期映射和版本控制。当 Major Rev 递增时，由于它不一定是数字，Innovator 需要提供序列中的下一个元素。提供这个新元素的序列就称为修订版。让我们来看一个示例：</p>
<p class="Content_body">以下是一个名为 Test 的条目的 ItemType（物料类型）定义。请注意，此 ItemType 定义的修订版名为 PartsRevision。</p>

<p class="Content_body">请注意，修订版只有两个属性——名称和实际的修订版列表。如果您正在创建此列表，请选择能够表示递进顺序、且容易识别其在某个元素之前还是之后的名称。</p>
<p class="Content_body">以下是 Test 的一个实例，名为 TestPart。请注意其初始修订版为 PartA。同时请注意，此条目处于"已发布"的生命周期状态。这意味着下次我们更新并保存该条目时，它不仅应该有一个新的世代编号，还应该有一个新的 Major Rev 或修订版。</p>
