<h1>关于版本</h1>
<p class="Content_body">条目的业务规则行为由其 ItemType（物料类型）定义的默认属性以及存储在条目实例上的生命周期状态属性决定。当条目实例在业务生命周期的状态之间流转时，其元数据或关系可能会发生变更（版本化）。这些变更会导致条目随时间进行重新标识，使用修订版、版本和代次属性来区分。版本化行为由 ItemType（物料类型）定义属性和当前生命周期状态附加的标志控制。</p>
<p class="Content_body">版本化可以作为自动或手动流程发起。当您选择自动流程时，每次条目发生变更（即锁定、编辑和解锁）时，条目的代次会递增。条目的生命周期会自动回退到生命周期起始状态。当您选择手动版本化时，只有在用户明确请求时才会递增版本。与自动版本化一样，代次会递增，生命周期也会回退到起始状态。</p>
<p class="Content_body">还加入了额外的逻辑来控制主版本号（Major_Rev）的递增。当条目实例的生命周期状态为发布状态时，对该条目的任何后续变更都会导致生成新的主版本号，同时递增代次并将生命周期回退到起始状态。</p>
