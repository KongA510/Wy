<h1>创建修订版</h1>
<p class="Procedure_Title">创建新修订版的步骤：</p>
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">从导航窗格中，选择 <strong>Administration&gt;Revisions</strong>。出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/revisionsmenu.jpg'">
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</p>
<ol start="2">
<li class="Numbered">点击 <strong>Create New Revision</strong>（创建新修订版）。出现一个空白的修订版窗口：
<p class="Figure_indented"><img alt="" :src="'/aras-images/rev1.jpg'">
<!--?rh-list_start level="1" an="1" class="rl-p-Figure_indented" style="list-style: rh-list;
list-style: rh-list;" ?-->
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</p>
</li>
</ol>
<ol start="3">
<li class="Numbered">填写以下属性：
<ul>
<li class="Bulleted_list">Name（名称） - 修订版的名称。</li>
<li class="Bulleted_list">Revisions（修订版） - 要使用的新修订版名称系列。这些名称应该是有序的，并且在顺序和递增方面易于识别。</li>
</ul>
</li>
</ol>
<ol start="4">
<li class="Numbered">点击 <img :src="'/aras-images/done.jpg'"> 以保存并释放此条目。</li>
</ol>
