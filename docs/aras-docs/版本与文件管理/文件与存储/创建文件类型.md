<h1>创建 FileType（文件类型）</h1>
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
<ol>
<li class="Numbered">在导航窗格中选择<strong>管理&gt;文件处理&gt;FileType</strong>。将出现以下菜单：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/ftmenu.jpg'"></p>
<ol start="2">
<li class="Numbered">点击<strong>创建新 FileType</strong>。将出现新的 FileType 窗口：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/ft1.jpg'">
<!--?rh-list_end ?-->
<!--?rh-list_start class="Numbered_list" level="1" style="list-style: rh-list;
list-style: rh-list;" ?-->
</p>
<ol start="3">
<li class="Numbered">在相应字段中输入文件类型信息。扩展名和 Mime Type 字段为必填项。</li>
<li class="Numbered">在"使用以下查看器查看"选项卡上，点击<strong>选择条目</strong>按钮 <img :src="'/aras-images/selitems.jpg'"> 以将现有查看器与该文件关联。将出现查看器搜索对话框。</li>
<li class="Numbered">点击<strong>运行搜索</strong> <img :src="'/aras-images/runsearch.jpg'"> 按钮以查看可用查看器列表。</li>
<li class="Numbered">从列表中选择一个查看器，然后点击<strong>返回所选</strong> <img :src="'/aras-images/returnselect.jpg'"> 按钮。</li>
<li class="Numbered">点击 <img :src="'/aras-images/save.jpg'"> 和 <img :src="'/aras-images/done.jpg'"> 以保存并释放文件。</li>
</ol>
