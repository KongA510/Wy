# 创建保险库
<p class="Content_body">在安装过程中，Innovator 会在 Innovator 服务器中创建一个默认的文件保险库目录，通常命名为 VaultServer。它还会创建一个虚拟目录，用于从网站提供对其他计算机上该位置的访问。您必须将保险库的 URL 设置为指向 Innovator 服务器保险库应用程序文件以定位保险库位置。有关设置保险库的更多信息，请参阅 Aras Innovator 安装指南。</p>
<p class="Content_body">您可以在不同位置或不同服务器上建立额外的保险库。每个保险库位置通过唯一的名称引用，并拥有自己的虚拟目录。</p>
<ol>
<li class="Numbered">在导航窗格中，选择<strong>管理 &gt; 文件处理 &gt; 保险库</strong>。将显示以下菜单：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/vaultmenu.jpg'"></p>
<ol start="2">
<li class="Numbered">单击<strong>创建新保险库</strong>。将显示一个空白的保险库界面：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/blankvault.jpg'"></p>

<ol start="3">
<li class="Numbered">在相应字段中输入保险库名称、URL 模式和 URL。</li>
<li class="Numbered">在复制规则选项卡上，单击<strong>选择条目</strong>按钮 <img :src="'/aras-images/selitems.jpg'"> 以添加身份组。将显示"身份搜索"对话框：</li>
</ol>
<p class="Figure_indented"><img alt="" :src="'/aras-images/idsearch.jpg'"></p>

<ol start="5">
<li class="Numbered">单击<strong>搜索</strong>按钮 <img :src="'/aras-images/searchicon.jpg'"> 以搜索相应的身份组。</li>
<li class="Numbered">选择一个身份组，然后单击<strong>返回所选</strong>按钮 <img :src="'/aras-images/returnselect.jpg'"> 将其添加到复制规则选项卡，如下例所示：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/reprule.jpg'"></p>
<ol start="7">
<li class="Numbered">单击<strong>转换服务器优先级</strong>选项卡，将转换服务器添加到保险库。</li>
<li class="Numbered">单击<strong>选择条目</strong>按钮。将显示"转换服务器搜索"对话框：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/conserver.jpg'"></p>
<ol start="9">
<li class="Numbered">单击<strong>运行搜索</strong>图标，查看可用转换服务器的列表。</li>
<li class="Numbered">选择适当的转换服务器，然后单击<strong>返回所选</strong>按钮 <img :src="'/aras-images/returnselect.jpg'"> 将其添加到转换服务器优先级选项卡，如下例所示：</li>
</ol>
<p class="Figure_indented"><img :src="'/aras-images/convservertab.jpg'"></p>
<ol start="11">
<li class="Numbered">单击 <img :src="'/aras-images/done.jpg'"> 保存并释放保险库。</li>
</ol>

</div>
